# 🚀 WSL Cybersecurity Lab

A personal cybersecurity lab built using Windows Subsystem for Linux (WSL2) with Kali Linux Rolling and Ubuntu 24.04 LTS.

This environment is designed for hands-on learning, penetration testing practice, Linux administration, automation, and CompTIA PenTest+ preparation.
